Wordle Arena

Can you win Wordle against an AI?

Built
June 2026

Why I made it

Language models had become surprisingly capable at tasks that look like human intuition. I wanted a fair, playable way to experience that competence rather than merely read about it.

What it became

Wordle Arena is a complete human-versus-Gemini game with separate boards, isolated feedback, asynchronous AI turns and the same information available to each player. The browser interface, game state, API and tests were built as one working system.

What happened

It became a small but complete public-facing experiment: a familiar game turns an abstract claim about model capability into a contest anyone can understand by playing.
