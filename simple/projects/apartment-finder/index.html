Apartment Finder

a GUI-agent experiment

A Mac agent that searched listings and assembled a real apartment shortlist.

Built
November 2025

Why I made it

Apartment search is not really a filter problem. The useful judgment lives in vague preferences, trade-offs, neighborhood context and details scattered across hostile listing interfaces.

What it became

I built a SwiftUI Mac agent that combined web search and retrieval, browser computer use, Claude Agent SDK orchestration and clarification questions. It navigated Craigslist and produced an apartment-research shortlist from my actual criteria.

What happened

It was a curiosity and a real personal task rather than a company. Still, it offered an early look at an AI acting as my delegate in a marketplace, carrying preferences across interfaces instead of making me manually operate every search box.
