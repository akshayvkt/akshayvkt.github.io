Gooey

Claude Code for people who don't live in a Terminal. Before Codex and Cowork apps existed.

Built
2025

Claude.ai and Claude Code use the same model. But one shows you how 2024 was, and the other shows you what 2026 will look like.

BUT, using Claude Code requires that you go where it lives - Terminal (AKA the green screen app you've seen from Matrix). It comes with a learning curve, and an interface that's not convenient at all. So we are in a world where only a small percentage have seen what the state of the art looks like.

As someone who was once not technical, I do not want to see that continue. That's why I built Gooey. With Gooey, my only goal was to show the vast majority of people who are not technical a glimpse of the future. An AI that can use your computer and work with files like you do. In an interface that requires zero learning.

I want it to not go into technicalities too much and instead ask me the kind of questions I can answer - about UX, about what the requirement actually is, what problem we're trying to solve, etc. I want it to be proactive - when we start a new session, instead of me having to start the conversation - I want IT to first review what the codebase is about (without wasting too many tokens) and then ask me what brings me there today.

I've so far used it to: organize my Downloads and Desktop, clean up my Mac's storage, find me apartments on Craigslist and create a powerpoint for it, search for leads for a project I was working on, and build itself.
